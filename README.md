# WebBuilder
Powerful Enterprise Rapid Web Development Platform

## Introduction
Welcome to WebBuilder!
WebBuilder is an all-in-one web application development & runtime platform. Relying on native AI capabilities, developers can build complete enterprise-grade systems automatically, quickly and accurately only with natural language or graphic descriptions.

## Core Features
1. AI Visual Development
Build business systems via natural language, screenshots and diagrams without heavy coding.
2. Enterprise-level Architecture
Stable, scalable architecture for internal management, business workflow and data platform.
3. One-click Deployment
Integrated runtime environment, one-click launch without complex environment configuration.
4. Low-code & Full-code Hybrid
Support both drag-and-drop low-code and custom code extension for flexible customization.
